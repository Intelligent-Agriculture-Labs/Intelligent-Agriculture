# Data sources

All sources were verified reachable on 2026-11-14 from both the Mac and the VPS; the Earthdata Login routes (GES DISC, NSIDC, LP DAAC) on 2026-11-15 from the VPS. IA needs **no API keys** by default: the Earthdata layers are optional enrichment (see [Earthdata Login layers](#earthdata-login-layers-optional)). Each source sits behind `backend/fieldshift/data/http.py`, which provides:
- a disk cache (TTL by data age);
- retries with exponential backoff;
- per-host rate limiting;
- a fallback chain: fresh cache → live → stale cache → committed demo cache → fuzzy offline match.

## Not used (yet) and why
- **GPM IMERG and GRACE-FO are used** (see the table and ADR-025). IMERG Final keeps coming through NASA POWER's anonymous `IMERG_PRECTOT`. Since the GES DISC EULA was approved on the project's Earthdata account (2026-11-15), the near-real-time Late/Early runs and the GRACE-DA percentiles come from GES DISC through Giovanni (ADR-027). Giovanni needs its own token from `/signin` (an EDL bearer token is rejected).
- **AppEEARS** (the earlier SMAP/ECOSTRESS route, ADR-012): both point requests submitted on 14 Nov were still `processing`/`pending` after > 24 h, so the pollers were stopped and the data are read directly from the archives (ADR-027). `scripts/appeears_smap.py` is kept for reference.
- **HLS (30 m NDVI):** needs a raster pipeline; stays in ROADMAP.md.
- **OpenET:** needs an API key. **NASS QuickStats:** needs an API key. Yield validation therefore uses national FAOSTAT yields (V10) and documented drought years (V5). County-level checks are on the roadmap.
- **Other drought labels considered for the global drought classifier (EXP-11):**
  - Australian Bureau of Meteorology rainfall-deficiency maps. They are rainfall-only, so as labels for a rainfall-driven model they would be close to circular. The BoM copyright terms are also not a blanket open licence.
  - Global SPEIbase (CSIC, ODbL). Climatic and monthly, computed from CRU, and again close to the model's own SPEI features.
  - GDO Risk of Drought Impact for Agriculture. It mixes in exposure and vulnerability, which is not hazard severity.
  - So the weak global label is GDO's modelled soil-moisture anomaly. It is independent of NASA POWER rain, but it is still a single indicator, and we say so wherever it is used.
- **CDL, SSURGO, PRISM:** US-only. IA's backbone is global so smallholders outside the US get the same product; these are planned as US-only enrichments.

## Earthdata Login layers (optional)
`backend/fieldshift/data/earthdata.py` reads credentials from, in order: `EARTHDATA_USER`/`EARTHDATA_PASS`; a `user:password` file at `$FIELDSHIFT_EARTHDATA_FILE` (default `~/.config/fieldshift/earthdata`, mode 600); a `~/.netrc` entry for `urs.earthdata.nasa.gov`. `FIELDSHIFT_EARTHDATA=off` disables the layers. The account needs the GES DISC ("NASA GESDISC DATA ARCHIVE") and LP DAAC/NSIDC applications approved.

| Layer | Route | Request cost per field |
|---|---|---|
| IMERG Late + Early rain (last 150 days) | Giovanni `/timeseries`, `GPM_3IMERGDL_07_precipitation`, `GPM_3IMERGDE_07_precipitation` | 2 requests, ~2.5 s each, 6 h cache |
| GRACE-DA groundwater / root-zone / surface percentiles (last ~400 days) | Giovanni `/timeseries`, `GRACEDADM_CLSM025GL_7D_3_0_{gws,rtzsm,sfsm}_inst` | 3 requests, 12 h cache |
| SMAP L4 root zone, surface, percentile (last 45 days, every 3rd day) | CMR granule search, then `opendap.earthdata.nasa.gov/…/<granule>.ascii?/Geophysical_Data/sm_rootzone[row][col],…` | 1 + ~16 requests, granules cached for a year |
| ECOSTRESS daily ET (last 60 days) | CMR point search, then the `_ETdaily.tif` COG (EDL bearer token → signed S3 URL → one-pixel GDAL range read) | 1 + one per overpass |

All requests run in parallel within a 15 s budget in `/api/advice` (`engine/live_layers.py`); what is not back in time is left out. Responses go through the same disk cache → demo cache → fuzzy offline chain as every other source (`http.cached_call`). Cache keys hold only the URL and its parameters: no username, password or token is written to disk, to logs or to the committed demo cache. Without credentials the app works exactly as before; the four demo fields still show these layers from the committed demo cache (`scripts/cache_earthdata_demo.py`).

## NASA FIRMS: modes and how to enable the full API
`backend/fieldshift/data/firms.py` chooses a mode from the environment.

| Setting | Behaviour |
|---|---|
| `FIELDSHIFT_FIRMS=auto` (default) **with** `FIELDSHIFT_FIRMS_MAP_KEY` (or `FIRMS_MAP_KEY`) | Area API for a 50 km box around the field. Sources: VIIRS NOAA-20, NOAA-21, S-NPP and MODIS NRT, last 2 days (`*_SP` standard processing when the as-of date is > 60 days old). 3 h cache. |
| `auto` **without** a key | Public keyless files `J1_VIIRS_C2_Global_24h.csv` and `J2_VIIRS_C2_Global_24h.csv` (~7 MB each, 3 h cache), filtered to 50 km. Recent dates only. |
| `FIELDSHIFT_FIRMS=demo` | Recorded detections only: `backend/fieldshift/data/firms_demo/*.json.gz`, recorded with `scripts/record_firms_demo.py` from the public 7-day feeds. |
| `FIELDSHIFT_FIRMS=off` | No FIRMS requests and no fire cards. The residue card still appears in burning regions and seasons. |

If live access fails, or `FIELDSHIFT_OFFLINE=1`, the module falls back to any cached file, then to the demo recording. The demo recording is used only if the field and dates are inside it. Otherwise the source is listed as `unavailable` and no fire card is shown.

To enable the full API:
1. Request a free MAP_KEY at https://firms.modaps.eosdis.nasa.gov/api/map_key/ (e-mail only; 5,000 transactions per 10 minutes).
2. Put `FIELDSHIFT_FIRMS_MAP_KEY=<key>` in `.env` or the service environment. Never commit it.
3. The key is used only in the request URL. Cache keys, logs and responses never contain it, and failed requests log only the HTTP status.

## Country data (ADR-027)
IA never uses one country's average for a field in another country. `backend/fieldshift/science/economics.py` looks up the field's country offline and takes prices, costs, currency, diesel, PV-pump cost, sowing dates and the yield factor for that country. Fallbacks (sub-region median, world median, scaled reference) are explicit: every response with money carries an `economics` block naming the country, currency, exchange rate and year, and the scope and years of each crop price. Coverage of the committed tables (built 2026-11-15): 252 countries/territories in the grid; 164 with FAOSTAT producer prices; 213 with a World Bank exchange rate; 200 with a price level; 176 with a World Bank diesel pump price (2016, brought to 2024); 151 with Sacks sowing dates; 191 with a country yield factor (41 from the benchmark). Rebuild with `scripts/build_country_data.py` on the processing host (`download`, `build`, then `yieldcal` locally).

## Harmonisation
Everything is reduced to daily point time series at the field location. IMERG is requested on UTC days and blended day by day with POWER's local-solar-time days; the offset (at most half a day) is below what the gauge validation could resolve (gauge days themselves end at varying morning observation times; the validation picks one common lag per station). GRACE stays monthly and regional. Coarser grids (POWER ~50 km, SMAP 9 km, GRACE ~300 km) are used as they are, and their footprint is stated in each card's caveats. Composites (MODIS 8- and 16-day) stay at their native time step and are compared with same-period climatology (2001→). No resampling invents detail that isn't there.

## Pre-cached demo dataset
IMERG extracts for the four demo fields were added with `scripts/cache_imerg_demo.py` (build_demo_cache.py now includes IMERG automatically, because the context builder requests it). GRACE needs no demo cache: its global asset is committed. `scripts/build_demo_cache.py` (run on the VPS) fetches every source for the demo presets (Fallon NV, Machakos KE, Córdoba ES, Ames IA), runs all endpoints in all six languages, and copies the gzip JSON payloads into `backend/demo_cache/`, which is committed. With `FIELDSHIFT_OFFLINE=1` the API never touches the network.

Rebuild (on the VPS, which holds the Earthdata Login; in a fresh clone, not a working copy with other changes): with an empty `FIELDSHIFT_CACHE_DIR`, run `scripts/verify_offline_demo.py --online` (every request the app makes, for the four presets, today and replay date, all six languages), then `scripts/build_demo_cache.py` (patient ORNL/satellite pass; merges into `demo_cache/index.json`) and `scripts/cache_earthdata_demo.py` (IMERG Late/Early, SMAP L4, ECOSTRESS, GRACE-DA; own empty cache dir). Copy `backend/demo_cache/` back and check it with `scripts/verify_offline_demo.py`: offline mode, an empty disk cache and all outbound sockets blocked; every app endpoint for every preset and language must return 200 with content, and the advice must carry SMAP L4, ECOSTRESS, GRACE-DA and (today) IMERG NRT. `--today YYYY-MM-DD` pretends a later day. Offline, a satellite analysis cached in an earlier week is served when the current week's is missing (its cache key holds the week).
