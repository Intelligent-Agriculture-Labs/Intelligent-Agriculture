# Contributing

- **Backend:** `cd backend && uv venv --python 3.13 .venv && uv pip install -e ".[dev]"`. Before committing, run `ruff check . ../scripts && ruff format --check . && mypy fieldshift && pytest -q`.
- **Client:** `cd app && npm ci`. Before committing, run `npm run lint && npm run typecheck && npm run format:check && npm test`.
- **Scientific functions** need unit tests with reference values (e.g. FAO-56 worked examples).
- **Thresholds, crop parameters and texts** go in `backend/fieldshift/config/*.yaml`, not in code. Log changes in `docs/DECISIONS.md`.
- **Farmer-facing text** goes through `t(key, lang)` with the key in `backend/fieldshift/config/messages/<module>.yaml` (or `t()` / `app/src/i18n/locales/*.json` in the app), in all six languages: en, es, fr, sw, hi, de. Keep `{placeholders}` and format specs identical. Check with `python scripts/check_i18n.py` (also run by `pytest`).
- **Model changes** need an entry in `docs/EXPERIMENTS.md`, and a rerun of `scripts/validate.py` on the processing host.
- **Never commit secrets or raw data dumps.** `backend/demo_cache/` is the only committed data, and it is generated by `scripts/build_demo_cache.py`.
- **Mock or synthetic data** must be labelled as such in code and UI.
- **Commits:** small, imperative messages.
